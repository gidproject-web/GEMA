Pilih cara membuat HTML

Gunakan salah satu jalur berikut sesuai platform AI dan hasil yang diberikan.

AI dapat menampilkan aplikasi atau game langsung; kode/ekspor opsional sesuai kemampuan platform.

LANGKAH 01

Buat dan salin prompt

Pilih kategori generator, lengkapi materi, tujuan pembelajaran, dan format HTML All-in-One, lalu salin prompt.

LANGKAH 01

Buka platform dengan preview

Tempel prompt pada platform yang mendukung pembuatan aplikasi, misalnya Gemini Canvas, Manus, atau Canva Code. Ketersediaan fitur tergantung produk dan akun.

LANGKAH 02

Jalankan dan uji preview

Buka pratinjau game atau website yang dihasilkan. Uji tombol, navigasi, respons, skor, restart, serta keterbacaan di HP. Beri instruksi perbaikan kepada AI jika hasil belum sesuai.

LANGKAH 03

Periksa kode jika tersedia

Jika platform menyediakan Code, Show Code, Download, atau Export, buka untuk memeriksa atau menyimpan hasil. Hasil ekspor tidak selalu berupa satu file HTML; beberapa platform menggunakan proyek multi-file.

LANGKAH 04

Bagikan sesuai fitur platform

Gunakan Share atau Publish jika platform menyediakan link aplikasi yang dapat diakses siswa. Uji link lewat mode penyamaran atau akun siswa. Link percakapan atau preview editor belum tentu link aplikasi publik.

LANGKAH 01

Minta kode HTML lengkap

Gunakan AI yang dapat memberikan source code, lalu minta satu file HTML lengkap dari <!doctype html> sampai </html>, termasuk CSS dan JavaScript bila memungkinkan.

LANGKAH 02

Simpan sebagai index.html

Tempel kode di VS Code atau editor teks, lalu simpan sebagai index.html dengan encoding UTF-8. Pastikan bukan index.html.txt.

LANGKAH 03

Jalankan dan uji media

Buka file HTML melalui browser. Untuk fitur kamera, fetch, modul, atau library tertentu, mungkin diperlukan localhost atau hosting HTTPS. Uji tombol, skor, restart, dan tampilan mobile.

LANGKAH 04

Publikasikan bila ingin tautan siswa

Untuk membagikan media sebagai URL, unggah ke hosting web statis seperti GitHub Pages; uji tautannya dari perangkat lain. Jangan menyimpan API key atau data pribadi di HTML publik.

LANGKAH 01

Buat Google Spreadsheet

Buka sheets.google.com, buat spreadsheet baru, beri nama misalnya Hasil Belajar GEMA. Siapkan sheet dan judul kolom persis seperti yang ditulis AI.

LANGKAH 02

Buka editor Apps Script

Dari Spreadsheet pilih Ekstensi → Apps Script. Proyek terikat Spreadsheet memudahkan penggunaan SpreadsheetApp.getActiveSpreadsheet(); untuk proyek mandiri gunakan ID Spreadsheet sesuai kode AI.

LANGKAH 03

Isi Code.gs

Hapus kode contoh bila tidak diperlukan, lalu tempel seluruh kode backend dari AI ke Code.gs. Periksa nama fungsi doGet() dan fungsi penyimpanan.

LANGKAH 04

Buat dan isi Index.html

Klik tanda + → HTML, beri nama Index (tanpa mengetik dua kali ekstensi .html). Tempel kode antarmuka dari AI ke file Index.html. Pastikan pemanggilan server menggunakan google.script.run bila diperlukan.

LANGKAH 05

Simpan, siapkan, dan beri izin

Simpan proyek. Jika AI menyertakan fungsi setup, periksa apa yang diubah lalu jalankan sekali dari editor sesuai instruksi. Setujui izin hanya jika sesuai kebutuhan; jangan meneruskan bila izin terlalu luas atau tidak dipahami.

LANGKAH 06

Deploy sebagai Web App

Klik Deploy → New deployment → ikon jenis → Web app. Pilih Execute as dan Who has access sesuai tujuan. Untuk penyimpanan terpusat, sering digunakan Execute as: Me, tetapi batasi akses dan validasi input karena aplikasi akan berjalan dengan izin pemilik.

LANGKAH 07

Uji tautan lalu bagikan

Gunakan Test deployments (/dev) untuk editor; gunakan tautan deployment (/exec) untuk siswa sesuai izin akses. Uji dengan data fiktif dan pastikan baris benar-benar masuk Sheet; setiap perubahan kode produksi memerlukan pembaruan deployment.

CEK SEBELUM DIBAGIKAN

Pengujian dan keamanan

✅ Uji fungsi

Periksa tombol, navigasi, skor, reset, penyimpanan, serta tampilan di laptop dan ponsel. Coba masukan salah dan data kosong.

🔒 Lindungi data siswa

Gunakan data fiktif untuk pengujian. Kumpulkan data seperlunya dan jangan membuka Google Spreadsheet mentah untuk publik. Jika web app dapat diakses luas, validasi dan batasi penulisan server.

📸 Kamera & AR

Uji izin kamera pada HTTPS atau localhost sesuai dukungan browser, sediakan tombol berhenti kamera dan alternatif mouse/sentuh. GAS bukan pengganti kebutuhan izin kamera.

🛠️ Revisi AI

Jika kode gagal, salin pesan error dan jelaskan tombol yang bermasalah kepada AI. Minta revisi file lengkap dan ulangi pengujian.

BANTUAN CEPAT

Masalah yang sering terjadi

HTML tersimpan sebagai index.html.txt

Aktifkan tampilan ekstensi file dan ganti menjadi index.html. Saat menyimpan di editor teks Windows, gunakan jenis berkas “All Files”.

Media HTML kosong / tidak bisa membuka kamera

Periksa Console browser. Beberapa fitur membutuhkan HTTPS atau localhost dan library dari internet; file lokal langsung tidak selalu cukup.

GAS menampilkan pesan fungsi doGet tidak ditemukan

Pastikan ada function doGet() di Code.gs yang mengembalikan HtmlService, lalu simpan dan perbarui deployment.

Data GAS tidak masuk ke Spreadsheet

Periksa nama sheet, pemilihan spreadsheet terikat vs memakai ID, izin, dan error pada Executions. Pastikan fungsi yang dipanggil lewat google.script.run benar, dengan withFailureHandler.

Siswa tidak bisa membuka tautan /dev

URL /dev adalah untuk penguji yang memiliki akses edit proyek. Bagikan URL Web App deployment /exec dengan pengaturan akses yang sesuai kebijakan sekolah.

Kode GAS diperbarui tetapi hasil siswa masih versi lama

Buka Deploy → Manage deployments → Edit, pilih versi baru, kemudian deploy pembaruan. Simpan kode saja tidak otomatis memperbarui URL produksi.
